隱私權政策 — Hermes 個人助理

最後更新：2026 年 9 月 16 日

一、簡介

「Hermes 個人助理」（以下稱「本應用程式」）是一套個人自用的自動化工具， 由使用者本人（以下稱「我」、「本人」或「使用者」）在自己的個人電腦上架設與執行。 本應用程式僅存取使用者自己本人的 Google 帳號資料，沒有其他使用者， 也不對外提供任何服務。

二、存取的資料與用途

本應用程式在取得使用者授權後，可能存取以下 Google 資料，且僅用於括號中說明的用途：

  • Gmail（gmail.readonly / gmail.modify / gmail.send）： 讀取與搜尋使用者自己的信件內容、標籤與寄件人資訊，用於產生每日摘要、 信件分類，以及代擬回覆草稿；僅在使用者本人明確確認後，才會以使用者本人的身分寄出郵件。
  • Google 日曆（calendar）： 讀取使用者自己的行程，用於每日簡報、衝突與空檔偵測；僅在使用者本人確認後才建立或修改行程。
  • Google Tasks（tasks）：讀取與建立使用者自己的待辦事項。
  • Google Drive / Sheets / Docs（drive / spreadsheets / documents）： 讀取與編輯使用者自己的檔案，用於產生個人報告與簡報。
  • Contacts（contacts.readonly）：唯讀使用者自己的聯絡人，用於辨識來信者。

三、資料的儲存與傳輸

  • 所有資料僅在使用者本人的個人電腦上處理與儲存。
  • 授權憑證（OAuth token）以本機檔案形式儲存於使用者自己的裝置，不會離開該裝置。
  • 資料不會被傳送、揭露或提供給任何第三方，唯一例外是使用者自行選用的 大型語言模型 API（用於產生文字摘要），且僅在使用者主動啟用該功能時才會呼叫。
  • 使用者可隨時撤銷授權，撤銷後本應用程式即無法再存取任何資料。

四、資料的分享與販售

  • 不販售使用者資料。
  • 不將使用者資料分享給廣告商、資料仲介或任何其他第三方。
  • 不使用使用者資料於廣告、個人化廣告或信用評估。
  • 不使用使用者資料訓練任何人工智慧或機器學習模型。

五、Google API Services User Data Policy 的 Limited Use 聲明

本應用程式對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy， 包含其中的 Limited Use 要求，具體而言：

  1. 僅基於提供或改善本應用程式中明顯可見、以使用者為中心的功能而使用 Google 使用者資料。
  2. 不將 Google 使用者資料轉移給第三方，惟下列情形除外： 為提供或改善明顯可見、以使用者為中心的功能所必要； 為符合適用法律、法規或強制執行的政府要求所必要； 為安全目的（例如調查濫用行為）； 或經使用者明確同意。
  3. 不使用 Google 使用者資料決定信用、貸款或就業資格，亦不用於廣告。
  4. 不允許人類閱讀 Google 使用者資料，惟下列情形除外： 使用者明確同意；為安全目的所必要；為符合法律規定所必要； 或資料經彙總且去識別化後用於內部營運。

六、安全性

授權憑證儲存於使用者自己的裝置，僅該裝置上的使用者帳號可讀取。 本應用程式不執行任何伺服器端資料庫或雲端儲存。
