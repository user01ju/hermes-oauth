Hermes 個人助理 (Hermes Personal Assistant)

Hermes 個人助理 是一套自架的個人自動化工具，由單一使用者（帳號擁有者本人） 在自己的電腦上執行，僅用來存取該使用者自己的 Google 帳號資料。

功能說明

  • Gmail：讀取、搜尋、分類自己的信件；代擬回覆草稿；寄送使用者本人確認過的郵件。
  • Google 日曆：讀取自己的行程、偵測時段衝突、建立使用者本人確認過的行程。
  • Google Tasks：建立與更新自己的待辦事項。
  • Google Drive / Sheets / Docs：讀取與編輯使用者自己的檔案，用於產生個人報告與簡報。
  • Contacts：讀取自己的聯絡人以比對來信者（唯讀）。

所有操作皆由使用者本人在自己的裝置上主動觸發，或依使用者自行設定的排程執行。

資料使用方式

本應用程式為個人自用工具，不是對外服務：

  • 存取的所有資料僅用於產生使用者自己看到的摘要、通知與草稿。
  • 資料僅在使用者自己的裝置與其自有的儲存空間中處理，不傳送給任何第三方。
  • 不販售、不分享、不用於廣告，也不使用資料訓練任何機器學習模型。
  • 本應用程式對 Google API 所取得資料的使用，遵守 Google API Services User Data Policy， 包含其中的 Limited Use 要求。
